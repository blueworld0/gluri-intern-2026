# 국내 산림 탄소 저장량 파이프라인

## 1. 확인할 질문

면적 × ha당 재적 × WD × BEF × (1+R) × CF로 국내 입목 지상부·뿌리 탄소 저장량을 공통 기준으로 계산함. 재적 공급자는 국가통계표와 재적 래스터를 교체할 수 있음. 고사목·낙엽층·토양은 제외함. CO₂ 환산은 44/12를 곱함. 연간 흡수량을 계산하는 도구가 아님.

이번 보완은 곰솔 BEF 불확도 112.782%를 원본에 남기면서 별도 덮어쓰기를 비교하고, 국가 인벤토리 임상별 계수와 혼효림 재적 배분을 독립적으로 비교했음.

## 2. 입력자료와 설정

입력은 시군구별 1:5,000 임상도, 대상 경계, SFS 2025·KOSIS 2020 원본 재적표, reference 계수 CSV임. `configs/`의 네 YAML과 [전체 파일 목록](FILES.md)을 참고함. 표 위치는 총계 제목과 Ⅰ–Ⅵ 머리글로 찾고, 소유 전체 총계 행 및 영급별 면적·재적 합계를 검증함. 활엽수는 총계−침엽수−혼효림으로 산출함. ZIP CP949 파일명을 복구하며 원본은 풀거나 변경하지 않음.

- `nifos2014_species`: 수종별 계수와 CSV 가중치를 사용함. `legacy_week4` 대응 프로필의 기본 혼효림 규칙은 `factor_average_50_50`임. 소나무·별칭·참나무·미등재 상록수 등의 이전 규칙은 [수종 대응 메모](reference/mapping_notes.md)에 기록했음.
- `forest_type_3`: 신재원 외(2023) 표 2의 임상 3종 계수임. `cf_mode: from_factor_set`을 지원하며 불확도 자료는 없어 고정함.
- `national_inventory_2025`: `national_inventory_factors_nid2025.csv`의 침엽수 WD/BEF/R/CF=0.46/1.43/0.27/0.51, 활엽수=0.68/1.51/0.36/0.48을 사용함. 수종그룹 코드를 사용하지 않음. 상록활엽은 활엽수에 포함하고, 죽림 NE·무립목지는 0으로 처리함. CF는 반드시 `from_factor_set`을 사용하며 계수별 불확도는 고정함. 출처는 [NID 2025, 표 6-9·BOX 1·6.2.1.2.3](https://www.gir.go.kr/home/board/read.do?boardId=90&boardMasterId=2&menuId=36)임.

`mixed_rule: factor_average_50_50`은 침엽·낙엽활엽의 WD·BEF·R·CF를 각각 평균한 뒤 곱함. `volume_split_50_50`은 혼효림 재적을 50%씩 나누어 각 계수 곱을 적용한 뒤 합침. 두 식은 다름. 국가 인벤토리 세트의 기본은 재적 분할임. 분할 방식에서 GPKG의 WD·BEF·R·CF는 요약값이며 실제 계산은 `carbon_conversion_tC_m3`와 `conifer_*`·`broadleaf_*` 성분 열에 기록함.

`uncertainty.overrides`의 기본은 `reference/uncertainty_overrides.csv`이고 `none`으로 끌 수 있음. 원본 곰솔 BEF_unc_pct=112.782는 그대로 두었음. 덮어쓰기는 11.62%이며 이유는 ‘원문 오기 추정. 침엽수 BEF 불확도 범위 상한 적용’, 근거는 ‘NID 2025 BOX 1 (침엽수 BEF 불확도 5.97~11.62%)’임. 공식 정오표로 확인된 정정값으로 단정하지 않음. 적용 후 unc_pct>50%가 남으면 경고를 출력하고 보고서에 표로 남기며 계속함.

임상도는 CP949로 읽고 EPSG:5179에서 자르며 면적을 계산함. 파일명 앞 두 자리로 시도를 판별하고 강원 42/51·전북 45/52·제주 49/50을 정규화함. 중복은 설정한 파일 순서·원본 행 순서에 따라 먼저 온 속성을 유지하며 제거 면적을 기록함. 미분류 코드는 행과 면적을 보존함. `boundary.path: none`이면 입력 임상도 전체임. 국립공원 ZIP은 `boundary.member: BSI_NPK_BBNDR.shp`와 `boundary.select: {NPK_NM: 설악산}`으로 선택할 수 있음.

재적 래스터는 **CRS가 지정된 단일 밴드 GeoTIFF**를 사용함. `volume.provider: raster`, `raster_path`, `edition`, `raster_unit: m3_per_ha | m3_per_pixel`을 지정함. EPSG:5179를 권장하지만 다른 투영·위경도 CRS도 지원함. 해상도는 제한하지 않으며 원자료 해상도(예: 30m)를 유지함. 픽셀당 재적은 실제 픽셀 면적(ha)으로 환산함. EPSG:5179에서 구획과 픽셀의 교차 면적으로 가중 평균하며 nodata·NaN을 제외함. 유효 픽셀이 없으면 결측으로 남기고 부분 피복 면적도 보고함. 임의 대체하지 않음. 이번 검증은 가짜 래스터만 사용했음.

## 3. 실행 환경과 순서

[Run_KFCS_Colab.ipynb](Run_KFCS_Colab.ipynb)는 **미실행** 상태임. CPU 런타임에서 첫 경로 셀의 `DRIVE_ROOT`, `EXPERIMENT_DIR`, 새로운 `RUN_LABEL`을 맞춤. 패키지 설치·경로 확인·원본 재적표 CSV 생성·단위시험 후 4주차 재현→2025 국가기준→금정구 검산→국가 인벤토리 순서로 실행함. 2025 보고서는 곰솔 덮어쓰기 적용·미적용 MC를 두 번 실행하고, 계수 세트·혼효림 규칙의 네 조합도 고정 비교함. 설정 탐색을 하지 않음.

필요 패키지는 geopandas, pyogrio, pyproj, shapely, pandas, numpy, rasterio, xlrd, openpyxl, pyyaml, matplotlib, pytest임. 설치·Drive 속도를 포함한 첫 실행은 약 10–30분으로 예상하며 전국 전체·고해상도 래스터는 더 오래 걸릴 수 있음. 결과 폴더가 이미 있으면 중단함. 로컬 실행 예시는 다음과 같음.

```bash
python -m kfcs.run --config configs/geumjeongsan_2025.yaml --drive-root /path/to/drive --output-dir /new/output/2025
python -m kfcs.run --config configs/geumjeongsan_national_inventory.yaml --drive-root /path/to/drive --output-dir /new/output/inventory
python -m pytest -q tests
```

원본 표에서 생성한 재적 캐시는 원본·파서 SHA-256이 일치해야 재사용함. 새 입력 또는 파서 변경 시 새 reference 캐시 폴더를 지정함. 배포용 reference에는 두 재적 CSV를 넣지 않으며 Colab 첫 실행에서 생성함. 이번 로컬 캐시는 Drive [02_분석결과](https://drive.google.com/drive/folders/13dHSpKDKMAVI7MbmWNuPDVocu5R5LGR2) / `20261113_국가기준저장량파이프라인_v01/local_validation/reference/`에 있음.

## 5. 확인한 내용과 남은 한계

- 금정구 검산에서 총량은 공식 통계와 대체로 맞지만(전체 면적 −3.4%, 재적 +2.9%) 임상별로는 크게 다름: 활엽수림 면적 +67%, 혼효림 −35%, 무립목지 −79%임. 우리가 쓴 2025 임상도와 산림기본통계의 임상 분류가 다르므로 임상별 결과는 주의해서 해석해야 함. FRTP=0은 비산림도 포함하여 공식 무립목지와 일대일 대응하지 않음.
- 경계는 4주차 자체 경계임(공식 국립공원 경계 GIS 미공개). 공식 국립공원 전체 저장량으로 해석하지 않음.
- 불확도는 계수 불확도만 반영함. 재적·면적 불확도는 미포함임. unc_pct는 95% 신뢰구간 반폭으로 해석하고 sd=값×unc_pct/196을 사용함. 같은 수종의 표본을 모든 구획·혼효 성분에서 공유하고 0 이하 값은 재추출함. CF·빈 불확도는 고정함. 보고 범위는 5–95%임.
- 국가 인벤토리 및 임상 3종 세트는 계수별 불확도 자료가 없어 고정함. 5–95% 범위가 한 값으로 나온 것은 실제 오차가 없다는 뜻이 아님.
- NID 방식의 계수·혼효림 배분을 적용한 **저장량**임. GIR 지역 공식 흡수량은 연간 변화량이므로 시간 범위와 탄소 풀을 맞추지 않고 직접 같은 수치로 비교할 수 없음.
- 시도 통계 재적은 개별 구획 실측이 아님. Ⅰ영급 0은 국가통계 규칙이며 실제 탄소가 없다는 뜻이 아님. 통계 공급자의 결측 키는 같은 시도 전체→전국 같은 임상으로만 대체함. 래스터 결측은 대체하지 않음.
- 외부 신재원 외(2023) 표 3은 2020년 위성 랜덤포레스트·토지피복 산림면적의 다른 방법 결과이며 정답이 아님. 부분 시도 AOI는 비교 불가로 보고함. 전체 시도 비교에는 공식 시도 도형의 피복 검증을 요구함.
- 기존 원본·4주차 코드는 읽기만 했음. 출력은 덮어쓰지 않으며 `.gitignore`에서 GPKG·local_validation·실행 캐시를 제외함.
