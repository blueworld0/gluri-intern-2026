## 1. 곰솔 BEF 불확도

원본 CSV는 곰솔 BEF_unc_pct=112.782를 유지했고 기존 4주차 원본과 SHA-256이 일치했음. 별도 uncertainty_overrides.csv를 통해 11.62를 적용했음. 원문 오기 추정이며 침엽수 BEF 불확도 범위 상한을 적용한 민감도 처리임. NID 2025 BOX 1의 5.97–11.62%를 근거로 기록했음.

## 3. 단위시험·재현 검사

**23개 시험 통과**했음. 기존 13개 외에 다음 10개 시험을 추가했음.

- 덮어쓰기 적용 후 메모리 원본과 원본 CSV가 그대로인지 확인했음.
- none일 때 >50% 경고·표시를 유지하는지 확인했음.
- 덮어쓰기 표의 원래 값이 원본과 다르면 중단하는지 확인했음.
- 같은 재적에서 혼효림 두 식이 다른 올바른 값을 내는지 확인했음.
- 국가 계수가 수종 코드를 쓰지 않으며 몬테카를로가 고정인지 확인했음.
- 재적 분할에서도 같은 수종 표본을 구획 전체에 공유하는지 확인했음.
- 국가 세트 기본 혼효림 규칙·CF 제한·기본 덮어쓰기 경로를 확인했음.
- 현재 설정이 none이어도 민감도 비교는 적용·미적용 두 경우를 계산하는지 확인했음.
- 공유 폴더에 작은 허용 파일만 남고 GPKG·큰 CSV가 제외되는지 확인했음.
- provenance의 URL은 유지하고 파일 경로만 상대화하는지 확인했음.

4주차 재현은 면적·탄소 모두 1% 허용 범위를 통과했음. 기존 1901개 구획을 공간 교차로 비교했음. GPKG 네 개를 다시 읽어 행 수·면적·탄소·44/12 환산을 검산했고, 입력·실행 코드 SHA-256 213건을 검사했음.
