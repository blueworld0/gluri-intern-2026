# 7주차 (11/13) — Meta 높이 지도 정확도 확인과 국가기준 저장량 파이프라인

## 질문
1. 국내에 쓰려는 Meta 1m 높이 지도는 실측 LiDAR(NEON)와 비교해 얼마나 맞는가?
2. 국가 온실가스 인벤토리와 같은 기준(면적 × ha당 재적 × WD × BEF × (1+R) × CF)으로 금정산 저장량을 다시 계산하면 4주차 결과를 재현하고, 최신 국가 통계로 바꾸면 얼마가 되는가?

## 한계
- Meta 모델이 NEON LiDAR로 학습됐을 수 있어 비교 결과가 실제보다 좋게 나왔을 수 있음. 국내 정확도는 따로 확인 필요
- 파이프라인은 로컬 원본으로 검증했고 Colab 노트북은 실행하지 않음. 재적은 통계표 평균이며 고사목·낙엽층·토양 제외
- 곰솔 BEF 불확도 112.782%는 원문 오기로 추정해 11.62%로 덮어쓴 결과를 함께 보고함(공식 정정값 아님)
