# 탄소 계산 참고자료

## 출처

국립산림과학원 (2014). 「한국 주요 수종별 탄소배출계수 및 바이오매스 상대생장식」. 최종보고서, 산림청. ScienceON 등록번호 TRKO201500013796.
- 원문: `국립산림과학원_2014_수종별_탄소배출계수_상대생장식.pdf` (93쪽, 저장소에는 포함하지 않음)
- 22개 수종, 수종마다 탄소배출계수 1쪽과 상대생장식 1쪽

## 파일

### `nifos2014_allometry.csv` — 상대생장식 (흉고직경 → 나무 무게)

| 열 | 뜻 |
|---|---|
| species | 수종 (보고서 표기) |
| form | `a*D^b` (흉고직경만 사용) 또는 `a*D^b*H^c` (흉고직경과 수고 사용) |
| part | 줄기, 가지, 잎, 뿌리 |
| a, b, c | 계수 |
| fit_R2 | 적합도 |
| DBH_min_cm, DBH_max_cm | 식을 쓸 수 있는 흉고직경 범위 (대부분 6–40cm, 강원지방소나무 6–70cm) |
| page | 원문 PDF 쪽 번호 |

- **D = 흉고직경(cm), H = 수고(m), 결과 y = 부위별 건중량(kg)**
- 지상부 바이오매스 = 줄기 + 가지 + 잎, 뿌리는 따로 계산
- 원문 검산 예시(39쪽): 강원지방소나무 흉고직경 24cm일 때 가지 = 0.069 × 24^1.995 = 39.6kg

### `nifos2014_carbon_factors.csv` — 탄소배출계수 (재적 → 바이오매스)

| 열 | 뜻 |
|---|---|
| WD | 목재기본밀도 (t/m³) |
| BEF | 바이오매스 확장계수 (줄기 → 지상부 전체) |
| R | 뿌리함량비 (뿌리 / 지상부) |
| *_unc_pct | 불확도 (%) |

- 임상도 방법: 탄소량 = 재적(m³) × WD × BEF × (1 + R) × CF
- 곰솔 BEF 불확도가 112.782%로 적혀 있다. 원문 표기 그대로이며 오기일 가능성이 있다

### `nifos2010_carbon_fraction.csv` — 탄소전환계수(CF, 바이오매스 → 탄소)

출처: 국립산림과학원 (2010). 「산림 온실가스 인벤토리를 위한 주요 수종별 탄소배출계수」. ScienceON TRKO201200009610. 원문: `국립산림과학원_2010_산림온실가스인벤토리_수종별_탄소배출계수.pdf`(저장소에는 포함하지 않음), 표 10 (PDF 50쪽)

- 국내 12개 수종의 목질부 탄소함량을 실측한 값이다. 범위는 0.472–0.509다.
- 보고서 결론: "탄소전환계수는 IPCC 기본값인 0.5와 거의 근사한 값(0.47–0.51)을 보여, 우리나라 산림 탄소계정에 기본값을 그대로 이용하여도 무방"
- 같은 보고서에 "탄소함량비는 IPCC가 제시한 0.5를 이용하고 있으며"라고 적혀 있다. 즉 **국내 인벤토리 관행은 0.5**다.
- **적용 방침:** 기본 계산은 0.5, 민감도 분석은 수종별 실측값. 보고서의 "해송"은 곰솔, "낙엽송"은 일본잎갈나무다.
- 2010년 자료이므로 최신 국가 온실가스 인벤토리 보고서(NIR)의 적용값은 별도로 확인하면 더 좋다.

### `kosis_nfi2020_volume_per_ha.csv` — 임상·영급별 1ha당 임목축적(재적)

출처: 산림청, 국가산림자원조사(제7차, 2020), KOSIS 통계표 「임상별 영급별 산림통계 표본점 단위면적당 임목축적」 (orgId=136, tblId=DT_136014_10210), 단위 m³/ha. 2026-10-30 KOSIS 화면에서 확인.

| 부산광역시 | 평균 | 2영급 | 3영급 | 4영급 | 5영급 | 6영급 이상 |
|---|---|---|---|---|---|---|
| 침엽수림 | 223.5 | 23.4 | 133.3 | 210.2 | 255.4 | 268.1 |
| 활엽수림 | 128.6 | 38.3 | 73.7 | 122.4 | 147.7 | 151.6 |
| 혼효림 | 174.8 | 54.3 | 107.9 | 167.2 | 196.2 | 224.4 |

- 전국, 경상남도(양산시용) 값도 같은 파일에 있다.
- **수종별이 아니라 임상(침엽수림·활엽수림·혼효림)별**이다. 임상도 방법에서는 "재적은 임상×영급 표에서, 목재밀도·확장계수·뿌리 비율은 임상도의 수종에 맞는 국립산림과학원 계수에서" 가져온다.
- 1영급 값은 표에 없다. 금정구 2025 임상도에서 1영급은 2개 구역뿐이라 2영급 값을 쓰거나 제외한다.
- 부산은 표본점 수가 적어 영급별 값이 흔들릴 수 있다(예: 침엽수림 2영급 23.4). 필요하면 전국 또는 경상남도 값과 비교한다.
- 실제 숲의 재적을 직접 잰 값이 아니라 표본조사 통계 평균이다. 같은 임상·영급이면 금정산 어디든 같은 재적으로 가정하는 것이다.

## 금정산 수종 대응표 (가정, 검토 필요)

서정범(2011) 야장에 나오는 수종 중 보고서에 공식이 없는 수종은 가까운 수종의 공식을 빌려 쓴다.

| 야장 수종 | 사용할 공식 | 근거 |
|---|---|---|
| 소나무 | 중부지방소나무 | 강원지방소나무는 강원·경북 북부용. 부산은 중부지방소나무 쪽이 가깝다고 판단 |
| 곰솔, 리기다소나무, 편백, 삼나무, 잣나무 | 같은 이름 | 보고서에 있음 |
| 신갈나무, 상수리나무, 굴참나무, 졸참나무 | 같은 이름 | 보고서에 있음 |
| 떡갈나무 | 참나무류 4종(상수리·굴참·신갈·졸참) 평균 | 같은 참나무속, 보고서에 없음 |
| 개서어나무, 소사나무 | 서어나무 | 같은 서어나무속 |
| 아까시나무, 밤나무 | 같은 이름 | 보고서에 있음 |
| 그 외 활엽수 (때죽나무, 비목나무, 산벚나무, 팥배나무, 오리나무 등) | 낙엽활엽수 공식들의 결과 평균 | 수종별 공식 없음. 가장 큰 가정 |
| 등나무 (덩굴) | 제외 | 나무가 아님 |

## 적용 범위 주의

- 식의 사용 범위는 흉고직경 6cm 이상이다. 야장에는 2–4cm 나무도 있으므로, **6cm 미만은 제외**하거나 따로 표시한다. 국가 산림조사 기준도 6cm 이상이다.
- 40cm를 넘는 나무(야장 최대 60cm)는 식의 범위를 벗어난다.
  - 야장 확인 결과: 6cm 미만 47그루(2.7%, 바이오매스 비중 약 0.06%), **40cm 초과 8그루(0.5%, 바이오매스 비중 약 4.5%)**. 40cm 초과 8그루 중 7그루가 소나무, 1그루가 곰솔이다.
  - 처리: **40cm 넘는 소나무는 강원지방소나무 식(적용 범위 6–70cm)을 쓴다.** 곰솔 1그루(최대 60cm 이하)는 곰솔 식을 외삽하고 표시한다. 6cm 미만은 제외한다.
  - (바이오매스 비중은 공식 적용 전, 흉고직경^2.4로 대략 추정한 값)
- 상대생장식은 전국 조사목으로 만든 식이다. 금정산 나무에 맞는지는 검증되지 않았다.
