# 8주차 (11/20) — 국내 NFI 표본점으로 본 Meta 높이 지도와 국가 재적표

## 질문
1. Meta 1m 높이 지도는 국내 제7차 국가산림자원조사(NFI) 표본점의 실측 높이·재적과 얼마나 맞는가?
2. 7주차 파이프라인이 쓰는 국가 재적표(임상·영급별 평균)는 그 자리의 실제 숲 재적과 얼마나 다른가?

## 한계
- NFI 재적도 국가 재적식 추정값이고, KOSIS 재적표는 NFI 표본점으로 만든 통계라 완전히 독립된 비교가 아님
- NFI 좌표는 약 10m 칸 정밀도. 100m 정밀도 표본점 181곳과 제주는 제외
- 표본점 하나(0.04~0.08ha)와 임상도 구획 평균은 크기가 달라 개별 차이가 큼

## 다음 단계
- 제외한 표본점(100m 정밀도, 제주) 위치 확인 후 다시 비교, Meta v2 높이 지도 비교
