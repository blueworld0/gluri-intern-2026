## 1. 질문·범위

금정구·북구·양산시 임상도 구획의 ha당 재적과 NFI7 현장 간재적을 비교함. 표본점 위치는 비공개로 처리함.

## 2. 입력·재사용 규칙

Drive 원본 NFI CSV·ZIP과 2025/2013 임상도, KOSIS 2020/SFS 2025를 읽었음. 기존 실험 KFCS의 임상도·코드·시도·재적표 처리를 직접 import함. 1영급은 0, 표의 6영급 이상은 6, 결측 대체 순서도 기존 파이프라인을 그대로 사용함.

## 3. 실행

코드(`run_check.py`)는 NFI 원자료를 다루므로 팀 저장소에만 둠. 7주차 [국가기준 저장량 파이프라인](../../week07/kr_forest_carbon_stock/)의 임상도·재적표 처리를 그대로 사용함.

## 5. 산출물·한계

결과: `outputs/`에 집계 CSV 8개, `report.md`, 그림 3장만 둠. 표본점번호·좌표는 결과의 private/에만 저장함. 공유 시 private/을 반드시 제외함.

- 표본점 하나(0.04~0.08ha)와 임상도 구획 평균은 크기가 달라 개별 차이가 큼. 평균 편향 위주로 해석함
- NFI 간재적도 국가 재적식 추정값임 (흉고직경 실측 + 식)
- KOSIS 2020 재적표는 7차 NFI 표본점으로 만든 통계라 완전히 독립된 비교가 아님. 다만 시도 평균과 그 자리 숲의 차이를 보는 데 의미가 있음
- 시점 차이: NFI 2016~2020 vs 임상도 2025(주), 2013(민감도)
- 임상도가 있는 3개 시군구만 대상 (부산 전체 284곳 아님)
