N 또는 E가 숫자 5자리+xx 형식이 아닌 경우 invalid_coordinate로 표시함. 해당 입력은 숫자 4자리+xx 형식이었으며 누락된 자리를 추정 보정하지 않았음. 이 때문에 분석에서 빠지는 점도 private에 모두 남겼으며 시군구별 n_bad_coordinate로 별도 집계했음. 산림 구획은 FRTP 1~4 및 FRTP 0 중 KOFTR 81~83으로 정의함. 산림 포함률의 분모는 산림·조사가능 전체임. 임상 일치율은 현장과 지도 모두 3개 임상으로 비교 가능한 점을 분모로 함. 전체 대비 임상 일치율도 함께 제시함. 두 지표 모두 유일한 최우수이며 차순위 대비 각각 2%p 이상 높을 때만 선택하도록 사전에 고정했음. 이는 통계적 유의성 검정이 아닌 중단 기준임.

다른 실험 비교: 지정한 Meta 대 NFI 체크포인트 파일이 없어 비교하지 못했음

죽림·무립목지·비산림 구획은 파이프라인의 0 값을 private에 그대로 남기고 주 재적 지표에서는 제외 표시했음. 제외 구획을 0으로 포함한 결과는 excluded_impact.csv에 별도 제시했음. FRTP 0은 원 코드가 무립목지/비산림을 합친 범주이므로 수종군 81~83을 무립목지, 91~99를 비산림으로 보조 구분하며 남는 코드는 구분불가로 남겼음.

중심이 구획과 교차하면 붙였음. 복수 구획의 정확한 경계에서는 기존 KFCS 파일 순서·행 순서를 따르고 복수 일치 개수를 표시했음. 경계 거리는 KFCS 중복 제거 후 구획 경계까지의 거리이며 5m 이하를 edge_flag로 표시했음. 좌표의 공개 정밀도와 표본원 크기에 따른 위치 불확실성은 남아 있음. 표본점을 오차 크기로 임의 제외하지 않았음.

## 재현과 검증

KFCS read_forest_maps·StatTableProvider·ensure_table을 직접 import했음. 시도 판별·코드 해석·구획 중복 우선순위·재적표 대체 규칙을 재구현하지 않았음. age1_rule=zero를 고정했음. ZIP 임분·일반정보와 재적 CSV를 집락·표본점·차기·연도 키로 1:1 대조했음. 입력과 읽은 코드 SHA-256을 provenance.json에 기록했음. 새 결과 폴더의 reference에만 원본 파서로 재적표를 생성했음. 좌표·번호는 private에만 저장했으며 공유 그림은 지도를 포함하지 않음.

## 한계

- 표본점 하나(0.04~0.08ha)와 임상도 구획 평균은 크기가 달라 개별 차이가 큼. 평균 편향 위주로 해석함
- NFI 간재적도 국가 재적식 추정값임 (흉고직경 실측 + 식)
- KOSIS 2020 재적표는 7차 NFI 표본점으로 만든 통계라 완전히 독립된 비교가 아님. 다만 시도 평균과 그 자리 숲의 차이를 보는 데 의미가 있음
- 시점 차이: NFI 2016~2020 vs 임상도 2025(주), 2013(민감도)
- 임상도가 있는 3개 시군구만 대상 (부산 전체 284곳 아님)
