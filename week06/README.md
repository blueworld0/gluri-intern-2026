# 6주차 (11/10, 11/12) — 국내(금정산) 적용 가능성과 면적 기반 방법 비교

## 질문
1. 5주차 NEON 나무 탐지 파이프라인을 국내 영상(국토지리정보원 정사영상)에 그대로 쓸 수 있는가?
2. 나무를 한 그루씩 찾지 않고 조사구 전체 높이 정보로 바이오매스를 추정하면 더 나은가?

## 한계
- NEON 23개 조사구는 내부 비교(독립 검증 아님). NEON LiDAR와 국내 Meta 높이는 다른 자료
- 금정산 야장(2009~2010)과 영상(2021) 약 10년 차이, 조사구 좌표 25~30m 오차

## 다음 단계
- 높이 분포 지표 시험, 지역별 보정, 국내 Meta 높이 지도 정확도 확인, 현재 시점 국내 실측(NFI 원자료 등) 확보

## 공개 범위
