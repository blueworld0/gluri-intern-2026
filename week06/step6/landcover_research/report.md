# Week06 Step 6-2 — 공식 토지피복·산림 공간자료 확보 방법

조사일: 2026-11-13 (한국 시간)

공식 공개 안내만 조사했다. 로그인·본인인증·자료신청·공간자료 다운로드·모델 학습은 하지 않았다. 기존 Week03~05와 Step5 입력은 변경하지 않았다. 이 문서는 확보 방법 조사 결과이며 실제 산림 표본 수를 새로 산정한 결과가 아니다.

## 1. 추천 데이터

**1순위는 EGIS의 2025년 세분류 토지피복지도 SHP와 분류 코드표다.** 점이 농경지·초지·수역 등에 속하는지 함께 판정하고 경계 중첩도 검토하기에 적합하다. 중분류는 같은 연도 세분류를 일반화한 자료로 소개되므로, 두 지도의 일치를 독립 검증으로 해석하지 않는다. 제공 형식과 제작 근거는 [EGIS 토지피복지도 안내](https://egis.me.go.kr/intro/land.do)에서 확인했다.

**산림청 대축척 임상도는 보완 자료**로 권한다. 피복 분류와 임상정보가 다르게 판정하는 점을 별도 검토하는 용도다. EGIS도 임상도 등 참조자료를 이용할 수 있어 두 자료의 일치를 독립 현장 검증으로 부르지 않는다. [EGIS 통계 작성 자료 안내](https://egis.me.go.kr/intro/stats.do), [산림청 임상도 제공 안내](https://map.forest.go.kr/forest/)

| 자료 | 공식 안내에서 확인한 제공 현황 | 권장 용도 |
| --- | --- | --- |
| EGIS 2025 세분류 | 전국, 1:5,000, 1m급, 41항목, SHP·PDF | 우선 확보할 산림/비산림 피복 판정 원자료 |
| EGIS 2025 중분류 | 전국, 1:25,000, 5m급, 22항목, GeoTIFF·SHP·PDF | 세분류 확보가 어려울 때 대안 및 일반화 영향 점검 |
| 산림청 2025 대축척 임상도 | 신청 대상에 1:5,000 / 2025 항목 존재 | 해당 지역의 갱신·속성과 실제 제공 형식을 확인 후 보완 |

1m급·5m급은 안내의 자료 수준이다. SHP가 1m 또는 5m 정사각 픽셀로 구성된다는 뜻은 아니며 실제 도형의 최소 분류 기준과 원본 축척도 확인해야 한다.

## 2. 2025년 지도와 관측시점의 차이

EGIS는 2025년 제작 세분류의 기본영상 촬영연도를 **2024년**으로 설명한다. 따라서 **2025년 지도라는 이름만으로 GEDI 관측일인 2025-04-25 당시의 피복이라고 단정할 수 없다.** 2025년 중분류도 이 세분류를 기초로 한다. 도엽별 촬영일·갱신 내역을 받아 개발·벌채·조림 등 변화 가능성이 있는 점을 따로 표시해야 한다. [EGIS 제작현황](https://egis.me.go.kr/intro/land.do)

산림청 화면은 2025 임상도와 2024 임상도(2020~2024)를 구별한다. 연도 선택만으로 대상 도형 전체의 조사일이 같은 해라고 판단하지 않고 지역별 갱신년도와 조사·판독 시기를 확인해야 한다. [산림공간정보서비스](https://map.forest.go.kr/forest/)

| 비교 기준 | 현재 확인 결과 | 추가 확인 |
| --- | --- | --- |
| GEDI 관측 | 2025-04-25 UTC | 기존 입력에서 확인 완료 |
| Sentinel-2 | 2025-04-28, 동일 제품의 밴드·SCL 사용 | Step5에서 처리 완료 |
| EGIS 2025 제작 세분류 | 기본영상 2024년 | 대상 도엽의 정확한 촬영일·수정 내역 |
| 임상도 2025 | 신청 항목 존재 | 대상 지역 갱신 여부·개별 도형 갱신년도 |

정확한 날짜가 없으므로 관측일과 지도 사이의 시차를 일수로 추정하지 않았다.

## 3. 공식 산림 분류 코드와 정의

아래는 **EGIS 토지피복 분류 코드**다. SCL 코드 또는 임상도 코드와 서로 바꿔 쓰지 않는다. 정의는 [EGIS 공식 분류체계](https://egis.me.go.kr/intro/land.do)를 요약했다.

| 산림 유형 | 중분류 코드 | 세분류 코드 | 공식 정의의 요지 |
| --- | --- | --- | --- |
| 활엽수림 | 310 | 311 | 임분 면적에서 활엽수림의 비중이 75% 이상 |
| 침엽수림 | 320 | 321 | 임분 면적에서 침엽수림의 비중이 75% 이상 |
| 혼효림 | 330 | 331 | 활엽수·침엽수 임분이 혼재하며 각 비중이 75% 이하 |

대분류 상위 항목은 산림지역 300이다. 75% 경계는 안내의 표현을 임의로 바꾸지 않았다. 실제 결합에서는 임분 비율로 새 코드를 만들지 않고 원자료에 부여된 분류 코드를 읽는다.

산림 안의 초지·나지 등도 별도 피복으로 구분될 수 있다. 법적 산림 범위, 임상도의 임분, 토지피복상의 산림지역, 단순 수목 존재는 같은 개념이 아니다. 연구에서는 우선 **토지피복 산림 코드와 일치하는 후보**로 명명한다.

주의: 위 숫자가 GeoTIFF의 저장 픽셀값 또는 SHP 필드명과 항상 동일하다고 가정하지 않는다. 실제 코드 필드명, 문자/숫자 자료형, 래스터 값-분류 매핑은 동봉 설명서에서 확인한다. 임상도의 산림/비산림 판정 코드와 2025 속성 스키마는 이번 공개 안내만으로 확정하지 않았으므로 임의 코드를 제시하지 않는다.

## 4. 대상 지역과 포함 여부

`week06/step5/outputs/vegetation_candidates.csv`의 고유 식생 후보는 **441점**이다. 모두 forest_status=not_assessed다.

| 항목 | WGS84 좌표 |
| --- | --- |
| 서쪽 경도 | 128.766124583°E |
| 동쪽 경도 | 128.999912750°E |
| 남쪽 위도 | 35.011331151°N |
| 북쪽 위도 | 35.226267955°N |

EGIS가 설명하는 전국 제공 범위에는 이 좌표권이 포함된다. 다만 **해당 도엽의 실제 검색 결과·공급 파일의 누락 여부·441점의 실제 포함 여부는 아직 확인하지 않았다.** 지도 검색의 사각형/다각형 선택으로 위 범위를 덮는 모든 도엽을 선택해야 한다. 임상도는 대상 지역 도형의 존재·2025 갱신 상태·발급 가능 범위를 별도로 확인한다.

점 중심 bbox와 경계 확인을 위해 UTM 52N에서 사방 100m 여유를 둔 신청 참고 영역을 `target_aoi.geojson`에 저장했다. 이는 신청 보조용 임의 영역이며 산림·행정 경계가 아니다. 도엽번호나 특정 행정구역을 추측해 지정하지 않았다.

## 5. 공식 확보 경로와 제공 방식 비교

### EGIS

공식 경로는 [자료신청 안내](https://egis.me.go.kr/req/intro.do) → 온라인 자료신청 → 신청 등록 → 자료신청 내역에서 다운로드다. 안내상 로그인 사용자 전용이며 제작연도·분류 수준·도엽을 선택한다. 지도 검색은 지점·사각형·다각형 선택을 지원한다.

공개제한 자료는 일반 온라인 제공이 불가하고 별도의 공문·신청서 및 방문 수령 절차가 안내돼 있다. 이는 **조건부 절차**이며 이번 대상 자료가 공개제한이라고 판정한 것은 아니다. 승인 소요시간·신청 수량 제한·비용·실제 파일 선택 옵션은 로그인 없이 확인되지 않았다. [공식 신청 절차](https://egis.me.go.kr/req/intro.do)

### 산림청

[산림공간정보서비스](https://map.forest.go.kr/forest/) → 산림공간정보 다운로드 무료신청 → 일반인 또는 공공/연구에 맞는 유형 → 대상 지도·연도 → 신청 위치 → 신청목적 등을 작성하는 경로가 안내된다. 본인인증이 필요하므로 이번에는 진행하지 않았다. [산림청 공공데이터 임상도 안내](https://www.forest.go.kr/kfsweb/kfi/kfs/trail/fTMap.do?mn=NKFS_06_08_02&pblicDataId=PBD0000059&subTitle=%EC%9E%84%EC%83%81%EB%8F%84&tabs=1)

현재 일반인용 원본 안내에는 임상도 TIFF가 표시된다. 반면 산림청의 과거 5차 임상도 자료 설명에는 Polygon SHP ZIP이 명시돼 있다. **과거 SHP 설명이 2025년 일반인 제공 형식까지 보장하지는 않는다.** 2025 벡터 SHP·속성표가 필요한 경우 공공/연구 신청의 제공 범위와 자격을 확인해야 한다. 업로드용 SHP 지원 문구를 다운로드 형식의 근거로 사용하지 않았다.

| 방식 | 로그인·절차 | 분석용 적합성 | 이번 확인 수준 |
| --- | --- | --- | --- |
| EGIS 온라인 원자료 | 로그인·신청 후 내역에서 수령 | 코드 속성을 가진 SHP 또는 분류 GeoTIFF가 적합 | 공식 안내 확인, 신청 미실행 |
| EGIS 공개제한 원자료 | 해당 시 공문 등 별도 절차 | 수령 형식·이용 조건 확인 필요 | 조건부 안내만 확인 |
| EGIS WMS | 지도 API 안내 제공 | 렌더링 지도이므로 원본 분류·도형 분석을 대체하지 않음 | 레이어 목록만 확인, API 미호출 |
| 산림청 원본전산파일 | 본인인증·유통신청 | TIFF가 코드 래스터인지 색상 지도인지 확인 필요 | 2025 신청 항목 및 TIFF 안내 확인 |
| 산림청 벡터 자료 | 신청 유형·버전별 확인 필요 | SHP와 속성·코드표가 있으면 공간 결합 가능 | 과거 SHP 제공 설명 확인, 2025는 미확정 |
| PDF·GeoPDF | 화면 조회·제공 옵션별 확인 | 지리참조가 있어도 분류 도형·코드를 자동 제공하지 않음 | 지도 확인용, 분석 원자료의 대체재로 권하지 않음 |

## 6. WMS와 분석용 자료의 차이

[EGIS 토지피복 맵 서비스](https://egis.me.go.kr/api/land.do)에 `lv3_2025y`, `lv2_2025y`가 등록되어 있다. WMS는 위치 확인과 배경 지도 비교에 사용할 수 있지만, 표시색을 역산해 441점의 산림 코드를 확정하는 방식은 사용하지 않는다.

공식 예제의 EPSG:3857은 지도 요청·표출 좌표계다. **배포 SHP·GeoTIFF의 원본 CRS를 입증하지 않는다.** WFS·WCS 원자료 제공이나 GetFeatureInfo의 분석용 신뢰성은 이번에 확인되지 않았고, WMS가 있다는 이유로 사용할 수 있다고 가정하지 않았다. 이번에는 GetMap·GetFeature·지도 타일 요청을 보내지 않았다.

## 7. 파일 형식·좌표계 및 Python 결합 방안

| 자료 | Python 적용 방식 | 확보 시 필수 확인 |
| --- | --- | --- |
| EGIS 세분류 SHP | 점과 polygon 공간 결합, 필요시 경계 거리·footprint 중첩 계산 | SHP·SHX·DBF·PRJ, 코드표·인코딩·수정 연도 |
| EGIS 중분류 SHP | 같은 방식으로 코드 310/320/330 판정 | 원본 필드명과 분류 매핑, 일반화 영향 |
| 분류 GeoTIFF | 점을 래스터 CRS로 변환해 코드 샘플링 | 원본 픽셀값-코드 매핑·NoData·CRS·해상도 |
| 임상도 SHP | 산림/비산림 및 임상 속성 공간 결합 | 2025 실제 제공 여부·코드표·지역 갱신년도 |
| 임상도 TIFF | 분류값 래스터일 때만 직접 샘플링 | RGB 지도인지 코드 래스터인지 먼저 확인 |

**2025 EGIS 배포 파일과 2025 임상도 파일의 정확한 EPSG는 이번에 확정하지 않았다.** 과거 산림청 자료에는 GRS80 TM 중부 원점 설명이 있으나 이를 새 파일에 그대로 적용하지 않는다. 원본 .prj 또는 GeoTIFF CRS를 읽고, 누락되면 제공기관 확인 전 공간 결합을 보류한다. UTM-K 등 서비스 안내를 임의의 EPSG 번호로 치환하지 않는다.

GEDI 위경도는 EPSG:4326이고 기존 Sentinel-2 결과는 EPSG:32652다. 벡터는 GeoPandas 등으로 CRS를 맞춘 뒤 공간 인덱스를 사용하는 결합을 설계할 수 있다. 래스터는 기존 rasterio로 각 점을 자료 CRS에 변환해 원본 분류값을 읽을 수 있다. 실제 도구 설치나 결합은 이번에 수행하지 않았다.

벡터 경계 위·다중 도형 중첩·무자료는 판정 불가로 따로 보존한다. 재격자화가 필요하면 범주형 자료에 최근린을 사용하며, 가능하면 원본 해상도의 분류와 GEDI footprint 주변 피복 비율도 별도 기록한다. 단순 중심점 하나의 피복이 footprint 전체 피복을 보장하지는 않는다.

## 8. 사용자가 실제 자료 확보 시 할 작업

1. **EGIS에서 2025년 세분류를 우선 선택**하고 후보 441점의 bbox와 여유 영역을 덮는 도엽을 지도에서 검색한다. 실제 검색된 도엽 ID·제작연도·판독 영상 시점을 기록한다.
2. 본인 계정으로 로그인하여 연구용 자료신청 절차를 진행한다. 이번 작업에서는 신청을 대신하지 않았다.
3. 분석 가능한 SHP 전체 구성 파일, 코드표, 좌표계, 대상 도엽 목록, 촬영·갱신 메타데이터를 함께 확보한다. 파일 옵션에 없으면 제공 가능 형식을 확인한다. PDF만으로 완료하지 않는다.
4. 세분류가 제공되지 않거나 제한되면 같은 연도 중분류의 코드 GeoTIFF 또는 SHP를 대안으로 확인한다.
5. 임상도가 필요하면 산림청에서 사용자 유형에 맞게 본인인증 후 2025 대축척 자료의 지역별 갱신·실제 제공 형식·속성 유무를 확인한다. 일반 TIFF가 RGB 지도라면 분석 코드 자료를 별도 문의한다.
6. 새 원본을 기존 자료와 분리해 보존한다. 이후 CRS·코드·시간·441점 범위 포함 검증을 거쳐 산림 후보·비산림·판정 불가를 산정한다. 기존 90점에도 같은 기준을 적용한다.

## 9. 확인의 한계와 근거

일부 EGIS 본문 직접 열기는 시간 초과, 산림청 공공데이터 안내 직접 열기는 403으로 실패했다. 해당 내용은 검색 도구가 제공한 **공식 사이트 색인 본문**으로 확인했다. 로그인 뒤 신청 화면·파일 옵션을 직접 조작하거나 자료 공급을 시험했다고 주장하지 않는다. 실제 자료의 크기·EPSG·속성 스키마·대상 도엽 번호는 미확정이다.

공식 출처 및 확인 내용은 `sources.json`, 분류 코드는 `forest_codes.csv`, 비교표는 `access_comparison.csv`, 로컬 대상 범위와 미확인 사항은 `research_summary.json`에 저장했다. 연구 결과는 **원자료 확보 경로와 코드 확인 완료, 산림 표본 수는 미확정**이다.
