## 확인할 질문

NEON에서 만든 나무 탐지 파이프라인(방법 A)을 금정산 국내 영상과 국내 공식으로 옮기면, 서정범(2011) 실측 조사구 50개의 실측 기반 탄소와 얼마나 맞는가?

## 실행 환경과 순서

Google Colab T4 GPU. `notebooks/GEUMJEONGSAN_DeepForest_2021.ipynb`. 입력 업로드 구조와 순서: [notebooks/README_colab.md](notebooks/README_colab.md)

- 탐지: DeepForest(11/06 HF 커밋 고정), score 0.2, patch 600, 25cm → 10cm 확대 입력, H ≥ 3m
- 흉고직경: Jucker 2017 구북구 계수 (침엽 1.004·0.73, 활엽 0.694·0.73, 혼효 평균), 바이오매스: 국립산림과학원 2014 (수종은 임상도), 탄소 ×0.5. 지상부만

**Colab 실행 중 직접 고친 부분 (로컬 노트북에는 미반영):**
1. `initialize()`: 교목층(T1)이 없는 조사구 5곳(야장상 T1 피복 0%)은 아교목층(T2) 최소 수고를 "보이는 나무" 기준으로 사용 (`top_layer` 열)
2. `rgb_crop()`: 정사영상 `merge(..., nodata=0)` 추가 (원본에 nodata 없음, rasterio 1.5.2 오류)
3. Meta CHM crop: `merge(..., nodata=np.nan, dtype='float32')` 추가 (정수형 CHM에서 nan 지정 오류)
