# 금정산 산림 탄소 PoC — 이연지

GLURI 기업체험형 인턴(부산대학교) R&D 과업 기록. 부산시 지속가능보고서에 쓸 **금정산국립공원 숲의 탄소저장량**을 공개 자료로 추정하고, 그 값을 무엇으로 확인할 수 있는지 주차별로 검토했다.

| 주차 | 주제 | 핵심 결과 |
| --- | --- | --- |
| [week02](week02/) | 원격탐사 + 머신러닝 AGB 추정 논문 3편 검토 (문헌고찰, GEDI 기반, 국가산림조사 기반) | 성능 숫자는 "무엇을 정답으로 썼는지"에 따라 의미가 다름. 무작위 분할보다 공간 교차검증이 필요 |
| [week03](week03/) | 홍천 시범 지역: GEDI + Sentinel-2로 바이오매스·탄소 추정 | 위성 모델 설명력 낮음(공간 교차검증 R² 0.19). 원인은 기준자료(GEDI) 노이즈와 광학 포화. GEDI 버전(V2.1→V3)만 바꿔도 탄소 총량 약 25% 차이 |
| [week04](week04/) | 금정산·부산대 캠퍼스: 현장 야장 / 임상도 + 국가통계 / GEDI 세 방법 비교 | 금정산 숲(약 5,336ha) 약 34만–54만 tC, 국가 통계 방식 약 54만 tC. 2009년 현장 야장(조사구 50개)과 현장 재방문 후보 75곳 확보 |
| [week05](week05/) | NEON(미국) 항공사진·LiDAR로 나무를 한 그루씩 찾아 탄소 계산, 같은 해 실측 기반 값과 단계별 비교 | 높이는 잘 맞음(상관 0.86). 가려진 나무를 못 찾아 탄소 과소 추정(실측 기반의 0.55배). 탐지 설정 조정으로 F1 0.38→0.55, 0.68배로 개선 |

각 주차 폴더의 `README.md`에 질문, 방법, 결과, 한계, 다음 단계와 실행 순서를 정리했다.

## 공통 원칙

- 공개 데이터 우선 (NASA GEDI, ESA Sentinel-2·WorldCover, 산림청 임상도, 국가산림자원조사, 국립산림과학원 계수)
- 무작위 분할 대신 **공간 교차검증**으로 성능을 확인
- 숫자마다 출처·가정·범위를 남기고, 가정을 바꾼 민감도를 함께 보고
- 인증 정보는 환경변수로만 읽고, 원문 저작물(논문 PDF 등)은 올리지 않음
