# week04 · 금정산 산림 탄소: 최신 바이오매스 지도(CCI v6)로 연간 흡수량 계산

## 1. 무엇을 하는 코드인가
- 3주차 코드(설악산 논문 방식 + 임상도 수종별 뿌리비율 R)에서 바이오매스 지도를 **v4(2017–2020) → v6(2015–2022)** 로 바꿨다.
- v4는 연도마다 값이 들쭉날쭉해서 연간 흡수량을 믿을 수 없었다. v6로 **8년 연속 값**을 만들어 연간 흡수량을 다시 계산하고, v4와 나란히 비교한다.

## 2. 계산 방법 (3주차와 같음)
```
탄소(tC) = Σ [ 나무 칸의 AGB(t/ha) × 칸 면적(ha) × (1 + R칸) ] × 0.5
CO₂(t)  = 탄소 × 44/12
연간 흡수량 = 2015–2022년 탄소의 직선 추세 기울기 (축적차이법)
```
- 범위: 임시 경계 67.45 km² (공식 경계 미공개) → 나무 칸 6,623 ha
- 나무 칸: ESA WorldCover 2020 / 뿌리비율 R: 임상도 2019 수종별 (평균 0.32) / 탄소비율 0.5
- 모든 연도에 같은 경계·나무 칸·R을 써서, 연도 차이는 바이오매스 지도 값의 변화만 반영한다.

## 3. 이번 주 바뀐 점
| | week03 | week04 |
|---|---|---|
| 바이오매스 지도 | CCI v4, 2017–2020 | **CCI v6, 2015–2022** (+ v4 비교) |
| 받는 곳 | NASA MAAP 사본 | **CEDA 원본** (로그인 불필요, 이용 목적 제한 없는 공개 라이선스) |
| 결과 | 연도별 저장량 | 저장량 + **연간 흡수량** + v4·v6 비교표 |

- Google Earth Engine에도 v6가 있지만, 무료 가입 조건(비상업)과 이 과제(부산시 수요)가 애매하게 걸려서 쓰지 않았다.

## 4. 결과 (임시 경계 기준)
| 연도 | 탄소밀도 (tC/ha) | 탄소 저장량 (tC) | CO₂ 환산 (tCO₂) |
|---|---|---|---|
| 2015 | 79.6 | 526,921 | 1,932,043 |
| 2018 | 85.6 | 566,702 | 2,077,906 |
| 2020 | 92.3 | 611,612 | 2,242,576 |
| **2022** | **90.6** | **599,844** | **2,199,427** |

- **연간 흡수량 (2015–2022 추세): 약 1.37만 tC/년 = 5.0만 tCO₂/년 (2.1 tC/ha/년)** · 계산법에 따라 1.0만 ~ 1.7만 tC/년
- v6는 같은 해 v4보다 10–20% 높고, 해마다 흔들림은 v4의 약 1/3
- 그림: `outputs/density_trend_v4_v6.png`, `outputs/bar_carbon_v4_v6.png`, `outputs/map_carbon_density_2022.png`
- 표: `outputs/stock_by_year_v6.csv`, `outputs/change_v6.csv`, `outputs/compare_v4_v6.csv`

## 5. 한계
1. 공식 경계가 없어 임시 경계를 썼다. 나무 칸으로 만든 경계라 숲 면적이 실제보다 클 수 있다.
2. CCI v6는 2022년까지만 있다. 2023년 이후는 다른 방법이 필요하다.
3. 지도 자체 오차가 크다(칸별 표준편차 합 기준 ±50–59%). 버전만 바꿔도 10–20% 달라진다.
4. 2020년 나무 칸 하나로 모든 연도를 계산해서, 숲 면적 변화는 반영하지 않는다.
5. 2022년 감소(−2.3%)의 원인은 이 자료로 알 수 없다.

## 6. 실행 방법
```bash
pip install -r requirements.txt     # 처음 한 번만
python run_all.py                   # 00 → 01 → 01b → 02 → 03 순서로 실행
```
- 위성자료(CCI v4·v6, WorldCover, DEM)는 코드가 금정산 주변만 잘라 자동으로 받는다. CEDA(영국) 서버가 느려서 v6는 연도당 1–3분 걸린다. 받은 파일은 건너뛰므로 끊기면 다시 실행하면 된다.
- **임상도는 직접 받아야 한다.** 공공데이터포털 '산림청_임상도'에서 1:5,000 2019년판 부산광역시(`26.zip`), 경남 양산시(`48330.zip`)를 받아 `data/imsang/busan_2019.zip`, `data/imsang/yangsan_2019.zip`으로 넣는다.
- `download_cci_v6.py`는 v6만 따로 받는 스크립트다(`00_download.py`와 같은 일).

| 파일 | 하는 일 |
|---|---|
| `src/config.py` | 설정값 (경계, CCI 판별 연도·주소, R 방식, 계수) |
| `src/00_download.py` | CCI v4·v6, WorldCover, DEM 받기 |
| `src/01_boundary.py` | 임시 공원 경계 |
| `src/01b_species_r.py` | 임상도 → 수종별 R 지도 |
| `src/02_carbon.py` | 판별 연도별 저장량·변화량, v4·v6 비교 |
| `src/03_maps.py` | 지도와 그래프 |
